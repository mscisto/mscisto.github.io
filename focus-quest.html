01 / The story

About the
project.

Focus Quest began as a fun personal project to help me stay focused while studying online. I kept checking Instagram and other social media websites during study sessions, so I decided to build a Chrome extension that blocks distracting websites.

Making focus feel like an adventure

To make the experience more personal, I added a Zelda touch. I wrote JavaScript that injects a HUD into the webpages I visit, showing Link walking and simulating an adventure while I study.

The challenge: one-time milestones

One challenge was making sure element milestones triggered only once, rather than repeating whenever I opened another webpage. I added a check and a hidden counter to track whether an event had already fired and prevent it from triggering again.

What I learned

Despite the hurdles, this was one of my most enjoyable personal projects. It helped me refine my HTML and CSS skills while learning much more JavaScript.

04 / Get started

Install Focus Quest.

Version 1.0.0 · Desktop Google Chrome · Manual installation from the ZIP. No Chrome Web Store installation is required.

Installation

  1. Download the project. Use the Focus Quest ZIP download and save it to your computer.
  2. Extract the ZIP. On Windows, right-click it and choose Extract All. On macOS, double-click the ZIP. Keep the extracted folder in a permanent location.
  3. Open Chrome’s Extensions page. Type chrome://extensions into Chrome’s address bar and press Enter.
  4. Load the extension. Turn on Developer mode, then click Load unpacked. Select the extracted FocusQuest-v1.0.0 folder that directly contains manifest.json. Select the folder, not the ZIP or the manifest file.
  5. Pin Focus Quest. Open Chrome’s puzzle-piece Extensions menu and pin Focus Quest. Click its toolbar icon to open the menu.

Start your first quest

  1. Enter a player name and choose Begin Adventure if this is your first launch.
  2. Open Block List and add the websites you want to avoid before starting a quest. Return to the main menu.
  3. Select The Minish Cap, then Begin Quest to start the 30-minute session. Visit a regular webpage to see the walking Link HUD and timer.

Helpful to know

Focus Quest uses website access to display the HUD and block selected sites during a quest. Quest progress and settings are saved using Chrome’s local extension storage.

Chrome cannot find the extension

Open the extracted folder and look for manifest.json. If it contains another FocusQuest-v1.0.0 folder, select that inner folder.

The HUD is not appearing

Refresh an existing webpage or open a new regular website. Chrome’s internal pages, such as chrome://extensions, cannot display the HUD.

After updating the files

Open chrome://extensions, click Reload on the Focus Quest card, then refresh your webpages. Keep the extracted folder where you installed it.

Turn it off or uninstall

Open chrome://extensions and switch Focus Quest off, or choose Remove to uninstall it.

Installation steps follow Chrome’s official unpacked-extension guide.
