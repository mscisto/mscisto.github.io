01 / La historia

Sobre el
proyecto.

Focus Quest nació como un proyecto personal para ayudarme a concentrarme mientras estudiaba en internet. No paraba de visitar a Instagram y otras redes sociales durante las sesiones de estudio, así que decidí crear una extensión de Chrome que bloqueaba las páginas que me distraían.

Convertir la concentración en una aventura

Para darle un toque más personal, incorporé elementos de Zelda. Escribí código JavaScript que inserta una interfaz superpuesta, o HUD, en las páginas que visito, donde Link camina y simula una aventura mientras estudio.

El reto: hitos que solo se activan una vez

Uno de los retos fue conseguir que los hitos de elementos se activasen una sola vez, en lugar de repetirse cada vez que abría otra página. Añadí una comprobación y un contador oculto para registrar si un evento ya se había activado y evitar que volviera a hacerlo.

Lo que aprendí

A pesar de las dificultades, este ha sido uno de los proyectos personales con los que más he disfrutado. Me ayudó a perfeccionar mis conocimientos de HTML y CSS y a aprender mucho más JavaScript.

04 / Primeros pasos

Instala Focus Quest.

Versión 1.0.0 · Google Chrome para ordenador · Instalación manual desde el ZIP. No requiere instalarla desde Chrome Web Store.

Instalación

  1. Descarga el proyecto. Utiliza la descarga de Focus Quest en ZIP y guarda el archivo en tu ordenador.
  2. Descomprime el ZIP. En Windows, haz clic con el botón derecho y elige «Extraer todo». En macOS, haz doble clic en el ZIP. Guarda la carpeta extraída en una ubicación permanente.
  3. Abre la página de extensiones de Chrome. Escribe chrome://extensions en la barra de direcciones de Chrome y pulsa Intro.
  4. Carga la extensión. Activa «Modo de desarrollador» y haz clic en «Cargar descomprimida» (Load unpacked). Selecciona la carpeta extraída FocusQuest-v1.0.0 que contiene directamente el archivo manifest.json. Selecciona la carpeta, no el ZIP ni el archivo de manifiesto.
  5. Fija Focus Quest. Abre el menú de extensiones de Chrome, identificado con una pieza de puzle, y fija Focus Quest. Haz clic en su icono de la barra de herramientas para abrir el menú.

Empieza tu primera aventura

  1. Si es la primera vez que la abres, introduce un nombre de jugador y selecciona «Begin Adventure».
  2. Abre «Block List» y añade las páginas que quieras evitar antes de empezar una aventura. Después, vuelve al menú principal.
  3. Selecciona «The Minish Cap» y luego «Begin Quest» para iniciar la sesión de 30 minutos. Visita una página web normal para ver a Link caminando y el temporizador.

Conviene saber

Focus Quest necesita acceso a las páginas web para mostrar el HUD y bloquear los sitios seleccionados durante una aventura. El progreso y los ajustes se guardan en el almacenamiento local de extensiones de Chrome.

Chrome no encuentra la extensión

Abre la carpeta extraída y busca manifest.json. Si contiene otra carpeta llamada FocusQuest-v1.0.0 , selecciona esa carpeta interior.

El HUD no aparece

Actualiza una página que ya tengas abierta o abre otra web normal. Las páginas internas de Chrome, como chrome://extensions, no pueden mostrar el HUD.

Después de actualizar los archivos

Abre chrome://extensions, pulsa «Volver a cargar» (Reload) en la tarjeta de Focus Quest y actualiza las páginas abiertas. Mantén la carpeta extraída en la ubicación donde la instalaste.

Desactivar o desinstalar

Abre chrome://extensions y desactiva Focus Quest o elige «Quitar» para desinstalarla.

Los pasos de instalación siguen la guía oficial de Chrome para cargar extensiones descomprimidas.
